# Mohd Afroj — Portfolio

A responsive, single-page portfolio built with HTML and CSS.

## Run locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Assets

- `assets/AI_Pic.png` — profile photo
- `assets/Resume.pdf` — downloadable résumé

The page is suitable for static hosting, including GitHub Pages. Google Fonts are loaded
from Google Fonts; system font fallbacks are included.
