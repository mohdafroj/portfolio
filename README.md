# Mohd Afroj — Portfolio

A responsive, single-page portfolio built with HTML and Tailwind CSS.

## Run locally

Install dependencies and build the stylesheet:

```sh
npm install
npm run build
```

Then open `index.html` in a browser or serve this directory with any static web server.
Rebuild the stylesheet after changing Tailwind classes. `npm run watch` rebuilds it while
you work. The generated stylesheet is checked in so static hosting, including GitHub Pages,
can serve the site without running a build.

## Assets

- `assets/AI_Pic.png` — profile photo
- `assets/Resume.pdf` — downloadable résumé

The page is suitable for static hosting, including GitHub Pages. Google Fonts are loaded
from Google Fonts; system font fallbacks are included.
